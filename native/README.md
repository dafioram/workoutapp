# Android app (Capacitor)

This folder builds an Android app from the web app in the parent folder. The
web app (the PWA on GitHub Pages) is unchanged. The Android app bundles the
same files and runs them in a WebView.

- **App name:** Workout
- **Package:** `com.dafioram.workout` (permanent once published)
- **Data:** workouts, settings and a cached copy of the exercise library are
  stored in Capacitor Preferences. The web app keeps IndexedDB.
- **Exercise library:** fetched from
  [exercise-data](https://github.com/dafioram/exercise-data) on first launch and
  checked for updates in the background, the same as the web app. After the
  first download the library works offline.

## Build

GitHub Actions builds the app: `.github/workflows/android.yml`. It runs on every
push and pull request, and can be started by hand (Actions tab, "Android build",
"Run workflow"). The result is `app-debug.apk`, under the run's **Artifacts**.
The APK is unsigned and for testing only.

To build locally you need JDK 21 and the Android SDK (platform 36, build-tools
36.0.0):

```sh
cd native
npm ci
npm run sync            # copies the web app into www/ and syncs it into android/
cd android && ./gradlew assembleDebug
```

## How the web app gets into the bundle

`scripts/prepare-www.mjs` copies the web files into `www/`. It lists the files
explicitly, so **if a new page or script is added to the web app, add it to
`FILES` there**, or the Android app won't have it.

`sw.js` isn't bundled. The app doesn't register a service worker inside the
Android app, because the files are already on the device.

## Not in this first build

- **Export and Import** (history backups, "Export workout") are hidden in the
  Android app. The WebView can't save files the way a browser does; this needs
  the Capacitor Share and Filesystem plugins.
- **Signing:** the APK is debug-signed. Release signing needs a keystore and
  signing settings in `android/app/build.gradle`, plus a signing config in
  GitHub secrets. It can be added later.
- **Icons and splash screen:** the default Capacitor icon is used. Generating
  them from `static/icons/icon-512.png` is a follow-up.

## Files

| Path | What it is |
|---|---|
| `capacitor.config.json` | App ID, name, and the bundled folder |
| `package.json` | Capacitor 8 and the Preferences plugin |
| `scripts/prepare-www.mjs` | Copies the web app into `www/` |
| `android/` | The Android project, generated by `npx cap add android` |
